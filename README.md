# 🎓 Online Learning Platform UI

A responsive and user-friendly front-end interface designed for an online learning platform. This project focuses on presenting educational content in a structured, visually appealing, and accessible way.

---

## 📌 Overview

This UI project simulates an online learning platform, allowing students to explore courses, view instructor profiles, and navigate content efficiently. It emphasizes modern layout design, responsiveness, and usability — similar to real-world educational websites.

---

## 🚀 Features

* 📚 Course listing with brief details
* 🖥️ Responsive navigation bar and layout
* 📱 Fully responsive design (desktop, tablet, mobile)
* 🎨 Clean UI with Bootstrap components

---

## 🛠️ Tech Stack

* **HTML** – Structure of pages
* **CSS** – Styling and layout
* **Bootstrap** – Responsive and grid-based design
